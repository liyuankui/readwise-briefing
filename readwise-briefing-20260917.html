⭐×5 🔬BrowserSkill — 让 Agent 操作你已登录的真实浏览器（腾讯开源）

来源：@shao__meng 推文（带 515 字架构长文）· 实体：github.com/Tencent/BrowserSkill

一句话：CLI（bsk）+ 浏览器扩展，任何能跑 shell 的 Agent 即可操作你日常浏览器的真实登录态；任务跑在独立 Agent Window 不打断你；标签页须显式借用、用毕归还；内置 human-in-loop（验证码/OTP 请人接管）。0.3.0 新增远程模式：云端 Agent 经一次性配对 + 可吊销凭证连回本地浏览器。

✅ 验证 + 🔬 亲测：MIT · TypeScript+Rust · 3002★ / 220 forks / 37 open issues · 创建 2026-06-22（3 个月）· 09-16 仍活跃 push · 已有第三方衍生（fastmoss-rpa-skills 50★）。隔离目录亲测：官方脚本 30 秒装好 bsk 0.2.1，命令面 Playwright 级（snapshot/observe/click/fill/emulate/network/screenshot…）。
⚠️ 小红旗：安装脚本未询问即向 ~/.bashrc、~/.profile 追加 PATH（本次已清理）；未连真实浏览器（故意的——零信任，配对动作留给人决定）。

为什么与你相关：① 与在用的 browser-use 形成互补而非替代——browser-use 开干净 Chromium，BrowserSkill 复用登录态，两者按场景分流；② 其 skill/SKILL.md 是「把纪律写进说明书」的范本：导航后引用失效必须重新 observe、不许凭旧截图点击、借用被拒即停手不许绕过、权限以浏览器侧设置为权威防 Agent 自我提权——对自建 Agent skill 有直接借鉴；③ 「云端 Agent ↔ 本地登录态浏览器」远程模式是 Agent 自主化拼图中稀缺的一块，但对企业场景同时是攻击面，采用前需安全评估。
