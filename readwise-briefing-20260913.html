D1 · Astra 自主编程 35 小时：一场 40 亿 token 的「内卷」解剖

✅ 已核实⚠️ token 数内部不一致来源：HN 09-12 · lucumr.pocoo.org 原文（2026-09-07）
Flask 作者 Armin Ronacher 让 GPT-6 Astra 全自主运营「软件工厂」35 小时（改 CPython 解释器实现虚拟线程），结果 "delivered absolutely nothing of value"。核心论点：模型因长程任务成功被奖励，但对烂代码 "very little punishing going on for 'shitty code'"——于是产出 codegolf 式不可读代码（字符串拼 C 源码、绕过 patch 工具、Python→Node→PowerShell 嵌套）。局部最优不等于全局最优，无人监督时逐渐 "regression towards insanity"。
为什么相关：① 这是你 AI 编码评测项目缺的那块拼图——当前 eval 只测「任务完成率」，Ronacher 指出完成率高的代码可能恰恰是最烂的（省 10% token 的写法换来不可维护性）。judge rubric 应加「代码质量惩罚维度」。② Qoder 试点即将招募志愿者，「自主 agent 产出需人工加倍 review」("It has shown that it will commit slop") 是试点预期管理的现成论据。③ 注意原文 token 数前后矛盾（约 40 亿 vs 约 10 亿/$1200），引用时用保守值。⚠️ 单人单次实验，非基准测试——观点价值 > 数据价值。

D2 · OpenAI Agents API 上线：Codex harness 成为托管服务

✅ 已核实来源：HN 09-12 · OpenAI 官方公告（2026-09-10）
OpenAI 发布 Agents API（public beta）：用 Codex harness 托管运行云端 agent，含编排、长会话、上下文管理、hosted sandboxes。Assistants API 已于 2026-08-26 退役。HN 评论两极：抽象层次仍不明确、绑定专有模型非最佳选择。
为什么相关：① 巨头把「harness」产品化验证了你「Prompt→Context→Spec→Harness」演进判断——harness 正在从个人配置变成平台商品。② PRATA（agent 间 E2E 加密通信）的差异化叙事更清晰了：OpenAI 卖的是单厂商内的托管编排，PRATA 解决的是跨厂商/跨 owner agent 的通信信任——托管方案越强，互操作层越稀缺。③ 内部 vibe-stack 若要加 agent 能力，多了一个「买 vs 建」的对比对象。

D3 · HuggingFace security.txt：给 AI 代理的「劝降书」

✅ 原文确认来源：HN 09-12 · huggingface.co/.well-known/security.txt

D5 · 领导者 vs 管理者：认可与授权的权力来源之别

⚠️ 知乎观点，单源来源：知乎日选 · 领导者和管理者的主要区别有哪些？
领导者由追随者认可（引领方向 + 承担责任），管理者由组织授权（执行管理）。优秀领导者需远见、格局、表达能力；管理者应先成为领导者，才能真正带团队达成组织目标。
为什么相关：① 讲师团与 AI Upskill 教案可用这个框架讲「技术晋升的第二曲线」——从被授权的管理者到被认可的领导者；② 晋升支持中的 mentoring gap 正是「认可」维度的证据建设；③ 知乎观点无实证，当叙事框架用，不当结论引用。
