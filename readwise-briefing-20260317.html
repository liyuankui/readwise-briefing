深度分析

核心洞察：Agent 是通用计算平台，类似 OS。垂直领域应该做 Skill/App，而不是重复造 Agent。

三层能力模型：

  1. Skill 层：基础工具调用
  2. Logic 层：封装逻辑节省 token
  3. Memory 层：保存用户状态

与你当前工作的关系：你的 mcp-server-odi、portal-cli 都是在给通用 Agent 做赋能，方向正确！

查看原文 →

技术洞察

rtk 原理：在命令和 LLM 之间加"过滤器"，智能压缩输出（去注释、空白、样板代码）。

效果：ls/tree 节省 80%，cat/read 节省 70%，测试输出节省 90%。

与你的关系：portal-cli 可以考虑集成类似的输出压缩逻辑。
