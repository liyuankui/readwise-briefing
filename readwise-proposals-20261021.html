P1 · Uber Genie 对评测体系的三点借鉴

正确性不靠模型自觉，靠结构 + 双真值

信号：Uber Genie Part 2（✅ ByteByteGo 转述，细节以 Uber 原博为准）· 连接：NL 断言层 / P2 evals 爬山环 / 讲师团
Genie 的正确性靠「仅基于带源材料作答」+ 双真值评估（judge 离线、用户反馈在线）。三点整体迁入：NL 断言层、evals 爬山环、讲师团案例库。

① 引用断言写入 NL 断言 schema（L1 断言，V2 验证）

断言验证分级

schema 增 citations[]:{url, span, supports}；不过即 eval fail——RAG 类应用的 eval-as-gate 终于有了程序化抓手。

② 48.9% 怎么读 + 用户反馈真值接入

48.9% 由用户反馈定义（154 频道、70K+ 问题、省约 1.3 万工程时）——证明不足半数有用也可净值为正，可接受基线取决于价值/成本比而非绝对分。它与 judge 评分是两种真值：前者海量带噪，后者可控但一致率 57-59%。接入设计（仿 Kafka→Hive）：👍/👎 埋点 → 反馈表（含 citations）→ judge-用户对齐率 → 分歧样本回流 few-shot 与断言库。

P2 · 「$260 一天造出 700 星教育工具」对 K12 意图的三点启示

以「学生自检」为 OpenMAIC 最小可行切入

信号：风清扬：初中/小学数学自检工具（✅ 推文自带数据；GitHub 链接未展开，repo 名不猜）· 连接：K12 教育 / OpenMAIC
AI 已把教育原型生产成本压到 $260 量级。K12 意图应以「学生自检」为 OpenMAIC 最小可行切入，以免费开源建立家长信任，用「一天冲刺出原型 + 审查流程收尾」的混合节奏替代全程多轮审查。

锁定痛点

OpenMAIC Plan 已过三轮审查，仍卡在 OpenNext 兼容验证——验证周期长于生产周期，原型到不了学生手里，既不能证真也不能证伪。

① 成本结构与可复制性

$260 ≈ 一个可用 K12 数学工具的全部 AI 生产成本。Free Tier 部署 + AI 编码之下，现金预算不再是瓶颈，节奏才是。冲刺与审查并非二选一：冲刺产骨架、审查保质量——为自检模块排 T+1 冲刺 + T+2~3 审查的混合循环。

② 「拒绝商用」的信号

作者拒绝全部商用（含国内教育机构）。K12 场景中家长对无商业动机的免费工具信任显著更高。落地：原型期即打「免费开源」标签；工具免费建信任，课程价值由讲师团承载，两条线分开核算。

③ 产品形态：自检 vs 教室

「学生自检」一天 700 星，因为单用户即闭环——自己测、自己看错因，无需教师侧与班级冷启动；「AI 教室」是多边形态，冷启动重一个量级。落地：课程先加自检模块，教室形态从使用数据里长出来。

里程碑与成功标准

W1 定位并试用源项目 + 自检一页 PRD → W2 OpenNext 兼容结论 + 自检 MVP 冲刺 → W3-4 ≥10 名学生内测、决定是否并入 L0。可测：OpenNext 1 周内明确结论；MVP 端到端跑通；≥10 人完成自检且 ≥6 人愿再来；原型 AI 额度 ≤$100。风险：源 repo 定位不到或质量差（只借形态不依赖代码）；LLM 判分出错（判分用程序，LLM 只做错因解释）；免费工具与收费课程混淆（双线明示边界）。

⚡ 本周三件事

  1. 展开 t.co 定位 GitHub repo，试用小学/初中两站，记录形态差距
  2. OpenMAIC 跑一次 OpenNext 最小验证（任一页面部署上 Cloudflare Free Tier）
  3. 自检模块一页 PRD + 2~3 名学生/家长 10 分钟访谈

🔴 诚实挑战

  1. 700 星是开发者社区热度，不等于学生/家长采用——K12 真指标是孩子反复用、家长愿推荐，只能靠内测回答。
  2. 单推文无法核实 repo 与实际质量，落地前必须定位、读码、试用。
  3. $260 是「熟手 + 清晰形态」的成本，首次复刻按 2~3 倍预算与时间预留。
