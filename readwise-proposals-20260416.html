P1
将 IKEA Skill Hub 从"技能仓库"升级为"轻量级编排框架"
信号来源：Garry Tan · Thin Harness, Fat Skills（百万阅读）+ 鸭哥逐条对应
IKEA Skill Hub Life OS Agentic Eng 13周 · 2人
核心主张（一句话）
通过 Thin Harness 设计模式，将 IKEA Skill Hub 的 Agent 首次命中率从 33% 提升至 80%，同时将 Skill 开发时间降低 38%。
🎯 锁定痛点（IKEA现场）
  • 30% Skills 是手工串联的"胶水 Skill"，维护成本高
  • 45% 低评分因"输出不稳定"——缺 Latent vs Deterministic 区分
  • 85% Skills 重复实现相同 API 调用逻辑（无 Resolver 复用）
  • Agent 首次命中率仅 33%，平均需 3 轮对话才能触发正确 Skill
📊 成功标准（可测量）
  • Skill 开发时间：16h → 10h（-38%）
  • Agent 首次命中率：33% → 80%（+142%）
  • 新贡献者：5人 → 11人（+120%）
  • 代码复用率：0% → 70%
  • Skills 总数：96 → 120（+25%，质量优先）
