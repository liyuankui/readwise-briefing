🔥 SkillOpt: Skill 也能"训练"了 — 微软联合上交复旦同济
karminski-牙医 · Twitter · 原文
Skill Hubmy-skill-evolverLife OS

微软联合上交复旦同济发布 SkillOpt 框架：让 AI 评估 skill 质量并不断优化。核心方法：

  • 独立优化器模型写 skill → Agent 执行试错 → 跑分验证 → 只有得分更高的 skill 变更才会留下来
  • 文本层"学习率"：每次只改一小部分（4-8 编辑操作/步最佳），最终接受 1-4 个核心修改
  • 被拒编辑缓冲区（反面教材记忆）+ 周期性元更新（盘点形成记忆）
  • 结论：Skill 应作为 Agent 的外部冻结状态被"训练"，Prompting 和 Training 界限模糊
为什么这是 THE 信号：Kyle 的 my-skill-evolver + project-harness 早已在做这件事——用 harness 闭环迭代 skill。SkillOpt 论文从学术角度验证了这条路，且提供了具体算法参数（学习率预算、编辑步数、rejected buffer）。GPT-5.5 准确率飙升 23.5 分说明 skill 训练 ROI 巨大。这不是"有趣"——这是"你已经在做的事被顶级团队证明正确了"。
