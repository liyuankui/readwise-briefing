GBrain — Y Combinator CEO 的 Agent 记忆系统

⭐⭐⭐⭐⭐
Akshay 🚀 (@akshay_pachaar) · 原文

GBrain 用 Markdown 文件夹作为 Agent 记忆的 source of truth。每个实体一页，分两层：

  • Compiled Truth（上层）：当前最佳理解，随新证据重写
  • Timeline（下层）：Append-only 证据链，永不编辑

知识图谱自动生成（regex，零 LLM 调用）。搜索层叠 20+ 确定性技术。

为什么与你相关：GBrain 的 Compiled Truth + Timeline 结构与你的 IRA 框架（Intent/Reality/Archive）高度同构。Life OS 的 Memory 支柱正缺一个具体方案——GBrain 提供了一个已验证的架构参考。特别是"Markdown IS the system of record"理念，与 Notebooks 的设计哲学完全一致。
