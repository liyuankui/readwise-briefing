P1 · 「验证文件」模式落地审查与无人值守体系

反驳日志记「AI 哪里错」，验证文件记「我验过什么」——互补双轨

信号：Larson: Self-Reinforcing Quality（✅ 全文）× Anthropic Scion（✅ 二手，方向佐证）· 连接：D1 练级场 / Gate 0 / P3 心跳 / 讲师团
每个 PR 与无人值守任务附一份 verifications 记录（已验步骤 + 未验之处）——审查从读代码猜对错，变为读证据判真伪。

锁定痛点

① 轮值审查者分不清「AI 说对」与「真验过」；② Gate 0 只收机器指标，缺人工侧证据；③ 无人值守任务失败后分不清「没跑」与「跑了没验」；④ 同一指导反复出现 = context poison。

三块落地

块动作
① 双轨合流（不合并）验证文件与反驳日志各立一份、以 PR 号互链——D1 反驳日志记 AI 错误→case bank；验证文件记已验/未验→审查信任依据；Gate 0 增「人工验证证据」项；P3 无人值守日报固定含「验证段」（即任务的 verifications）
② /dismiss{reason}对 AI 审查意见采纳或拒绝均须带理由；反驳日志加「dismiss 理由」字段——无理由 dismiss 记为无效轮值；理由沉淀入 case bank
③ context poison→工具沉淀同一指导出现 ≥2 次即触发沉淀为模板/skill 检查项，停止口头重复

里程碑与成功标准

W1 模板定稿 + 2 试点 PR → W2-3 D1 轮值全量带双轨 + Gate 0 人工侧上线 → W4 P3 日报验证段 + 首次 context poison 盘点。可测：试点期验证文件覆盖率 ≥80%；审查往返轮次 4 周后较基线下降；无理由 dismiss = 0；case bank 月增 ≥5 条带理由案例；无人值守日报验证段覆盖率 100%。ROI：每 PR 约 5 分钟记录换审查者免于复现；重复指导工具化后编写时间下降。风险：形式主义（抽查+互查）；低风险 PR 摩擦（分层豁免）；双轨膨胀（定期归档）。
