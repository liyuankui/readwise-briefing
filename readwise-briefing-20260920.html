① JEV — 「不是语言模型」的决策模型，最火用例是 coding agent 上下文压缩

⭐×5⚠️ Partial🔬 已亲测（源码）
推文 1：@SUOHA_AI（09-19）· 推文 2：@SUOHA_AI（09-19）
「JEV 是前 OpenAI、参与 ChatGPT / RLHF 的 @CompleteSkeptic（Diogo Almeida）创办 @typesafeai 后的第一款模型。他在 OpenAI 时发现了一个致命矛盾……」

「大家在 Claude Code 里写长代码，最恶心的就是上下文一满，系统就卡住 10 秒去写总结小作文。开发者 @tamarajtran 刚刚开源了这个插件：利用 JEV……连 JEV 联创都亲自下场转发点赞」
⚠️ Phase 1.5 验证（属实 + 有争议）
✅ 属实：Diogo Almeida 确为 RLHF/InstructGPT 共同发明人（typesafe.ai 09-16 发布）；JEV 非 LM——输入文本+类型化问题，输出类型化答案+置信度，不生成文本；官方称 20-200x 快（~100ms）、40-400x 便宜（输入 $0.042-0.20/MTok，输出免费）；Pydantic 文档已收录。
⚠️ 争议：Theo (t3.gg) 批评病毒式 demo「benchmark 表现差」；latency 有出入（官方 ~100ms vs 竞品实测 ~400ms）；发布 2 天已现 6 个 clone。
🔬 生态亲测（clone 源码）：tamaratran/fast-jev-compaction（Claude Code 插件，MIT，src+tests 完整）——verbatim pruning 哲学：绝不重写内容，Jev 对每个 tool call 只答两个类型化问题（keepCall? / keepResult?），低于阈值即删/截断；状态分阶段塞入 25k token，请求分片并发。jerryfane/omp-jev-compaction（1135 行 TS）补了关键工程层：prompt-cache 意识——重写 prefix 会打爆 cache，故决策「记住而非重算」（sticky 模式），16,198 条真实消息回放：40 请求仅 3 次 rewrite、0 次 prefix break。
为什么与你相关：三条当前主线同时命中——① compaction 质量是 harness 变量，AI Coding Eval 的 model × harness 矩阵缺这一维；② 「决策/生成分离」是 agent 架构新分层，Life OS 的 Proactive Agents 正需要高频低成本决策原语；③ JEV 式 typed verification（不能生成文本 → 结构性防幻觉）直指昨天「验证分层协议」方向 A 的 L0-L1 自动验收层缺口。

② Ternary Bonsai 2 27B — 三值量化过了「日常可用」阈值，笔记本能跑 27B

⭐×5✅ Verified🔬 已亲测（生态）
推文：@PrismML（09-19）
「Today, we're announcing Ternary Bonsai 2 27B. Based on Qwen3.8 27B, Bonsai 2 27B is 9x smaller than its full-precision counterpart while retaining 98.2% of its aggregate benchmark performance. Two months after the first Bonsai 27B release, the biggest change is quality.」
✅ Phase 1.5 验证（全部属实）
✅ HF 官方 GGUF 权重存在，Apache 2.0；98.2% / 9x / 5.9GB 数字与推文一致；262K context + 推理模式；RTX 5090 143 tok/s，M5 Max 本地 46.8 tok/s。
🔬 生态亲测（repo 检索）：MLX 生态已适配（mlx-dspark：Apple Silicon 4x 解码加速，原生支持）；llama.cpp 官方 fork 支持 2-bit；第三方 tool-eval-bench 已有结果（score 85 / deployability 80）；r/LocalLLaMA 社区正面讨论 PQ2_0 变体。
为什么与你相关：① opencode 提案选型清单的自然候选——27B 模型 5.9GB 落进笔记本内存，「低成本国内模型」从云端单价优势扩展到本地零边际成本；② AI Coding Eval 应把「量化模型 × 编程任务」纳入评测矩阵（98.2% 是聚合 benchmark，编程子集 retention 未知——这本身就是个好实验）；③ 学习价值：三值 QAT 开源实现（ternary_QAT）是 CS336 量化的现成教材。

  • 本周可做：下载 Ternary Bonsai 2 GGUF（5.9GB）到 M5 Max，llama.cpp/MLX 跑 FTP（file targeted edit）小样本，对照全精度 Qwen3.8 27B——为 opencode 提案补「本地模型」一节
  • 排期：AI Coding Eval 增补 harness 维度：compaction 策略（原生 summary vs JEV verbatim vs 无）× 长任务成功率受控实验（见 Proposal A）
