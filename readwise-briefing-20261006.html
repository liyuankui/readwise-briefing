1. Fenng 的中文技术文档写作 Skill（借鉴 STE 思路）✅ Verified🔬 亲测

10-05 · @Fenng · repo: fenng/Tech-Doc-Style-Chinese（⭐1406，10-05 仍在更新）

"这个版本新增了借鉴 STE (Simplified Technical English) 思路的中文技术写作规则，用于减少歧义和操作错误。已经快 500 个 Star 了。"（推文时点数据；仓库当前已达 1400+）

🔬 亲测（SKILL.md 全文）：规则优先级（事实保真 > 用户约定 > 术语准确 > 结构语气 > 排版）+ 事实保真细则（不得把"可能"改写成确定事实、缺口标"待确认"）——工程质量高，非口号式规范。

与知识库 AGENTS.md「R·输出」中 ASD-STE100 中文移植条款完全同源。两步落地：① 装入个人 skill 库作日常写作校对器；② 作为讲师团「AI 时代的写作规范」课件素材。

2. magpie：任意订阅 × 任意 Agent 的模型路由器✅ Verified🔬 亲测

10-03 · @indie_maker_fox · repo: yetone/magpie（⭐5126，MIT，活跃更新）

"magpie 把「任意订阅/任意 agent 产品」里的模型，一键代理给「任意其他 agent 产品」用——可以在 codex 里跑 deepseek、grok。"

🔬 亲测（README）：本地 gateway 统一管理 35+ agent 的模型配置，只改各 agent 配置文件里那一个 key；配额耗尽自动切账号；macOS 菜单栏操作，支持 Docker/Linux。与宣传一致。

「订阅 × 模型解耦」正是低成本国产模型编程提案的底层论据：工具选型与模型采购可以分层决策。个人设备先试用，公司设备走合规边界确认后再议（见 D4 Proposal）。
