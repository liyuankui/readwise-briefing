⭐×4 过度思考让 LLM 变笨（已回源）

Why Thinking More Can Make an LLM Dumb✅ 全文已读

11-17 · ByteByteGo

简单问题首答已对，模型却生成多达 13 个解法；多余推理可能引入错误假设把对改错（9:00 → 9:10）。机制：token 生成使后续推理建立在早期输出上；训练评分只看最终正确性（GRPO），无法区分简洁与冗长的正确答案 → 模型不知何时停。缓解：首个正确解答 + 一次检验处截断——token 2408→1331，准确率几乎不变（93.0→92.8）。

对 eval 线直接有用：① 「不知何时停」正是 agent 疲劳（人脑版）的模型版同构——两者都缺停止判据；② 「首答+一验截断」的 token 减 45% 无损，恰是爬山环的成本优化范式；③ judge prompt 设计警示：让 judge 想更多可能更差——简洁 rubric 优于长链推理。原文
