① Muse Glimmer — Meta 30B 开源本地 agent 模型 ✅ Verified ★★★★★
30B 参数、Apache 2.0、为「always-on 本地 agent」设计。4-bit 量化 <20GB，推测解码加速，多模态感知编码器，~76% SWE-Bench Verified。已上 HuggingFace meta-models/Muse-Glimmer-30B，支持 Ollama/MLX/llama.cpp。HN 991 分 / 561 评论。

② Docker Sandboxes — AI 编码 agent 的 microVM 隔离 ✅ Verified ★★★★★
Docker 新独立产品。每个 sandbox = 一个自带内核的轻量 microVM（macOS 走 Hypervisor.framework），Docker 自研 VMM。让 Claude Code / Gemini CLI / Codex / Copilot CLI 在 YOLO 模式（全自动、无逐条确认）下安全隔离运行。即起即弃。
源：Docker Blog · Andrew Lock 实测 · HN 讨论
Life OS「Software Factory」的物理隔离底座——agent 敢真放权写代码的前提是炸不坏主机；Trust & Eval pillar 缺的就是这道墙。缺口：microVM 不挡外发网络（有案例 agent 上传 5.1GB），需另配 egress 控制。Kyle 已装 docker 29.4，未装 sbx CLI。
