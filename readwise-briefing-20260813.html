⭐×5 极致压缩 ① Needle 2 — 14 MB 的智能体大模型，跑在树莓派/微控制器
Cactus Compute 出品，45M 参数、单文件 14MB、全 session 仅 28MB RAM（2-bit 量化）。专为 工具调用 / 设备控制 / 结构化抽取 设计，树莓派 5 上 ~500 tok/s，ESP32-S3 也能跑。
✅ 已验证 · 🔬 值得亲测 | 官网 · GitHub · HF 模型
为什么相关：直接喂给 SLM Agent Benchmark 研究——验证「小模型 + 工具 > 大模型裸奔」的最极端一端（45M vs 32B）。14MB 能跑在 ESP32 上 = K12 教育里"每个学生口袋一个 AI"的硬件基线。Kyle 的 M4 Pro 跑它绰绰有余，甚至无需 GPU。
⭐×5 本地原生 ② h3.c（H3-metal）— Redis 之父用纯 C+Metal 在 Mac 上跑 MiniMax-H3
作者 antirez（Salvatore Sanfilippo，Redis 创造者）。纯 C + Metal，无 Python / 无 PyTorch，原生优化 Apple Silicon，测试 M3/M5 Max。MiniMax-H3 是开源全模态模型（文本/视频 2K/音频）。
✅ 已验证 · 🔬 值得亲测 | GitHub · HN 讨论 · MiniMax 开源公告
为什么相关：三重价值——(1) CS336 第一性原理：一个顶级系统程序员从零写推理引擎，是读"推理引擎如何工作"的最佳活教材；(2) 国内模型 + 本地：MiniMax 是中国开源模型，呼应 opencode-proposal 的国产模型方向；(3) ⚠️ Kyle 的 M4 Pro 24GB 对完整视频生成偏紧（社区在 M5 Pro 64GB 上跑），但文本/音频 + 读源码完全可行。
⭐×5 信任面裂痕 ③ 可从 Anthropic/OpenAI/Google 的 API 窃取加密推理痕迹
论文 arXiv:2608.09867：把前沿模型返回的加密 CoT 推理块重放给同厂商更弱、防护更弱的"兄弟模型"，即可解码出隐藏推理，绕过反蒸馏机制。可批量收割用于训练竞品模型。
✅ 已验证 | 论文 · CyberSecurityNews
为什么相关：这把刀直接架在 Kyle 每天调用的 Claude/GPT API 上——他的 Agent 大量依赖这些 API 的推理输出。公理"信任面=攻击面"的活教材：(a) 评估自家 Agent 的推理数据暴露面；(b) 作为 AI Security 的真实案例沉淀到 credential-manager / 安全公理库。
