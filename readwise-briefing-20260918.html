🌿 生活维度信号

🧠 健脑 · System One / System Two：决策模型命名背后的心智模型

Jev 的命名直接取自 Kahneman《思考，快与慢》的双系统理论——System 1（快、自动、廉价、易偏）vs System 2（慢、刻意、昂贵、可靠）。今天的信号把这个 2011 年的心智模型变成了 2026 年的工程架构：LLM 是 System 2，decision model 是 System 1。迁移到个人认知：并非所有决策都值得调用“慢系统”，识别生活与工作中哪些判断可以交给低成本直觉例程，是注意力管理的同构问题。
