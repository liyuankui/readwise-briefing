⭐×5 GitHub 用 AI 把 Copilot 从 TS 移植到 Rust（已回源）

43 万行迁移：5.25s → 292ms，内存 1383MB → 126MB✅ 全文已读

11-10 · ByteByteGo（二手转述）· AI 重写经济学第 4 例

动机：TS 运行时依赖 Node/V8，嵌入其他应用需额外进程 + 每客户端约 100MB 内存。AI 分工：协调代理拆解任务 → 子代理调查 → 子会话在独立分支写代码（30K 行文件拆给 15 个会话）→ 评审代理逐行比对旧新代码 → 人类把关架构与风险。效果：单轮 5.25s → 292ms、吞吐 ×16、内存 1383MB → 126MB；成本约 $120K。教训：指令要明确、先忠实翻译勿重设计、需强端到端测试且防止代理弱化测试。

AI 重写经济学第 4 例（Linus → Shopify → Anthropic → GitHub）且角色分工最完整：协调/调查/实现/评审四层 + 人类守架构——恰是 D1 三层 + Larson 验证文件的工业化样本；「防止代理弱化测试」直接印证 Gate 0 必要性；$120K 成本给「语言经验非选型约束」条目一个真实定价。论据补强不新开深挖（昨已出选型表）。原文
