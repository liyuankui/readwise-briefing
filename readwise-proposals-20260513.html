A · Engineering Baseline 安全

🛡️ NPM 供应链防御加固：把口头的7天规则变成机器强制

Engineering Baseline Skill Hub AI Starter Kit
在攻击者的 6 分钟窗口之外安装依赖，是目前成本最低、收益最高的供应链防御。IKEA 已有 7 天口头规则，现在是用一行配置把它变成机器强制的时候了。

  • Skill Hub：npx skills update 推荐每周运行，每次是攻击入口

📏 成功标准

  • 100% 受管理安装路径强制 7天冷却
  • 0个未守护的 pull_request_target workflow
  • 有 runbook，演练过一次凭证轮换
  • Bootstrap 无裸 npm install -g

🗓 里程碑

M1（本周2h）：bunfig.toml + .npmrc 写入 minimumReleaseAge=604800秒
M2（第2周1天）：扫描 GHES/GitHub 所有 pull_request_target workflow
M3（第3-4周）：Skills Hub 安装门控 + AGENTS.md R9.1 升级为机器强制
M4（第4-6周）：Bootstrap脚本锁定版本 + checksum
M5（第6-8周）：Dependabot/Socket.dev 每日扫描闭环

C · AI Upskill Trainer

🧠 工程灵魂注入：AI Output Review（AOR）判断力模块

AI Upskill Trainer Engineering Baseline Software Testing
AI Upskill Trainer 不是工具培训，是判断力培训——教人知道 AI 对了什么、错了什么、以及为什么。

🎯 AOR的操作定义

  • 给学员一段AI生成的代码/分析/建议
  • 限时10分钟找出其中问题
  • 评估3维：逻辑性·假设链·可维护性
  • 终点：改出更好的Prompt（不停留在"AI不可信"）

📏 成功标准（可测量）

  • 训练后 ≥70% 学员能识别≥1个假设（训练前 <30%）
  • ≥50% 学员能提出≥1个反驳（训练前 <20%）
  • PR Review 中"AI生成代码存在X问题"评论 ≥3次/周（基准≈0）

🗓 里程碑（插入现有L0-L4，不另立体系，10周）

M-J1（第1-2周）：设计AOR框架（3维评估卡片），嵌入L1-CB结尾
M-J2（第2-3周）：L1.1 FAR Cycle Review阶段加入AOR 10分钟练习，题库5道
M-J3（第4-6周）：L3-AOR工程师模块——用真实Copilot代码做Review训练，60分钟课程包
M-J4（第7-8周）：讲师校准——3名讲师达到"能带学员找出AI错误"的认证标准
M-J5（第9-10周）：Pilot班AOR前后判断力对比，输出得分报告

⚡ 立即行动（本周）

1
周二前：私信3-4名工程师收集"AI犯错"真实案例（脱敏），这是AOR模块的地基
2
周三前：在L1.1教案FAR Cycle Review阶段预留"[预留10分钟] AOR练习"插槽
3
周五前：找1名资深工程师做非正式AOR基准测试——给一段AI代码，看他发现了什么、用了多久

🔴 诚实挑战

Rob Pike说的是系统编程领域，CDH是零售业技术团队，IKEA版本的"失魂"是丧失业务逻辑判断力而非算法理解力。若课程只展示"AI会犯错"而不给修正工具，结果是更焦虑不更有能力——AOR必须以"发现→修正→预防"三段式结束。
