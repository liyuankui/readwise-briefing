Proposal #1 Life OS · 首个 Proactive Agent

⭐×5 · ✅ Verified来源：@rionaifantasy 推文 + Rion-Wu-tech/wechat-intelligence-hub
以 wechat-intelligence-hub 为参考实现而非依赖，四周内在本地 Mac 把「微信补读/找记录/捞待办」改造为每日 07:30 自动简报的只读 Proactive Agent——自持核心路径 ≤500 行，数据不出本机。

锁定的痛点

  • 补读群聊每日 15-30 min（上下滑屏怕漏）；跨群跨月找历史消息每周 3-5 次常失手；群聊口头待办（"我发你""回头聊"）无 capture 靠记忆——同源问题：聊天数据是死数据（无 index / 无 digest / 无 routing）。

里程碑（~14h / 4 周，Gate 制）

M内容Gate
M0 侦察+基线（本周）private fork 留档；虚构数据 demo 隔离试跑；实测 3 天微信手动动作基线A：demo 通且基线 ≥15 min/天，否则换靶
M1 真实数据下水本人授权 key → 单群历史入 SQLite → CLI 检索B：3 个真实查询 ≤30s 命中；key 提取失败即降级/Kill
M2 Proactive 层launchd 07:30 → 24h 简报 → 通知推送连续 5 个工作日零人工干预
M3 路由+评估action items → 意图清单提案制；每周抽查 recall召回 ≥80%（抽查 20 条口头待办）

ROI

  • 直接回收 ~15h/月；Life OS 五支柱中 Proactive Agents + Memory + Trust & Eval 三线首次打通；方法论验证为模板，下一站 Teams/邮件（合规成本低得多）。

风险与缓解（节选）

风险等级缓解
DMCA 下架（腾讯已下架 30+ 同类 repo）高本周 private fork + 本地 vendor；只借架构模式；核心路径自持
项目仅 2 天成熟度（macOS key 路径作者未实测）高当参考不当依赖；锁 commit；Gate B 不过即降级或 Kill
供应链投毒（新库 + 高权限读加密 DB）中高真实数据前安全审计 + 虚构数据隔离试跑
账号封禁（只读也违反 ToS）中禁用 key helper；不 hook 不注入不外发；低频访问

本周 3 件事

  • 基线测量 3 天（15 min/天）——Gate A 的证据
  • private fork + 虚构数据 demo 隔离试跑 + 安全审计（2h）
  • 半页提案入意图清单 review/，写明 Gate B / Kill 标准
诚实挑战（节选）：① 前提可能不成立——工作主战场若在 Teams/邮件，微信基线 <15 min/天则 ROI 崩塌，应死于 Gate A（警惕"新玩具效应"）；② 主号承载十年社交资本，为省 20 min/天赌 ToS 灰色地带，期望值可能为负；③ 推文"发现赚钱机会"是营销话术——真正要的 digest+search+action items 只占 repo 能力的 10%，别被 scope 带跑；④ 若月维护 >3h，降级为手动触发检索工具。

Proposal #2 讲师团内容骨架 + 个人学习主干

⭐×5 · ✅ Verified来源：@astaxie 推文 + cs329z.stanford.edu
借 CS329Z（2026 秋，9/23 开课、讲义逐周免费公开）作「骨架供应商」，把 L0-L4 教案从"从零创作"降为"本地化改写"（制作成本降约 60%）；同一课程作个人 Agentic 工程主干，替代停滞的 CS336——一份投入，讲师团与个人两用。

补查的关键事实

  • Fall 2026 课表 9/23-12/2 共 20 讲；今日 slides 尚未发布（逐周释出）；readings 均为公开 arXiv/博客；无 license 声明；prereq 为研究生级（CS224N/CS336）→ 只适合作 L2-L4 素材，非入门层。

里程碑（~18h / 12 周 ≈ 1.5h/周）

M时窗产出
M0 素材地图 v1本周（2h）HF Agents Course + Anthropic Courses + CS329Z readings 三源目录 → curriculum-map.md（每源标 L 级）
M1 骨架对照表9/14-9/27（6h）大纲每模块 ← 素材源 + 场景替换位 + 练习三件套；启动会带此表
M2 教案试点 ×210/5-10/19（6h）L1.1（入门）+ L2.0（RAG+Tool Use，跟课同步开发）；验收：非技术讲师试讲 20 min
M3 CS336 决策点≤10/26（1.5h）一页 decision doc：continue / pivot / pause 三选一
M4 L3-L4 补全11 月-12/15（3h）Eval / LLM-as-Judge / Safety / Coding Agents 模块

成功标准（节选）

  • 大纲模块 ≥90% 具"源+案例+练习"三件套；单套教案制作 ≤8h（无骨架基线 20-25h）；≥2 名讲师（含 1 名非技术）基于骨架独立产出；CS336 状态 10/26 前去僵尸化。

本周 3 件事

  • 60-90 min 建 curriculum-map v1（三源目录 + L 级标注）
  • 30 min 升级启动会材料：加"骨架计划 + 9/23-12/2 跟课表"，兼作讲师招募话术
  • 30 min 起草 CS336 decision doc；日历钉 9/23 首讲 + 每周跟课 block
诚实挑战（节选）：① 最弱一环——赌"降门槛→易招讲师"未经验证，讲师团成败在招募激励不在素材；② 进度外包给斯坦福课表，11 月撞期先死的是跟课；③ CS329Z 对 L0/L1 贡献≈0，救入门层的是 HF 级内容——推文兴奋感不该绑架素材选择；④ 换轨可能是沉没成本的美化，decision doc 必须回答"底层理解对讲师角色是否 load-bearing"；⑤ 18h 估算无 buffer，以 M2 实测为准。

Proposal #3 Agent-Ready Baseline（ARB）

⭐×3 · ⚠️ Partial来源：@dashen_wang 推文（观点，不可独立验证，价值在框架）
Agent 编程工具的效率下限由底座环境决定，而非模型：缺 rg/trash/websocat/ssh 免密的机器上，agent 只能用慢、危险、甚至交互卡死的替代品——把 30 分钟 Mac 环境基线写进 Starter Kit bootstrap，是保住低成本模型（DeepSeek/GLM）红利最便宜的杠杆。

审计清单（env-audit.sh，三层分级）

层项缺失时 agent 行为
P0 安全trash-put / trash回退 rm，不可逆
P0 安全ssh 免密（BatchMode 验证）密码交互，agent 卡死
P0 速度ripgrep回退 grep，repo 级搜索慢一个量级
P1fd · sd · jq回退 find/sed/awk，慢且脆
P2 能力websocat · fzfWS 握手测不了；人机选择降效

里程碑（~13h / 4 周）

  • M0 写 env-audit.sh 并本机跑通（3h，<100 行轻量脚本）→ M1 修 mac-bootstrap.sh 已知失败点 + 并入 P0 安装段（5h）→ M2 团队 Mac 实测收 1 周数据 → M3 嫁接 opencode 提案：cost-analysis 加"环境折损"节（2h）→ M4 固化进内部 skill 库（2h）。

成功标准（节选）

  • 团队 audit 覆盖 12/12；P0 三项达标率 ≥90%；新机 bootstrap 后 P0 通过率 100%；opencode 提案 draft v2 含环境章节；1 份 rg vs grep 实测数据。

本周 3 件事

  • 写 env-audit.sh 并本机跑通（含 ssh BatchMode 检查 + micro-benchmark）
  • 修 mac-bootstrap.sh 已知失败点 + 加 P0 三行安装
  • opencode 提案 draft 增"运行环境基线"小节 + 2 位工程师试跑 audit
诚实挑战（节选）：① 因果链未证——"环境好→agent 效率高"是合理推断非 A/B 结论，提案中只能作定性论据；② 样本小，环境是加分项不是主菜（占 draft 篇幅 >15% 即越界）；③ 信号本身不可验证，引用必须标"启发性框架"；④ agent 真实回退行为未实测（sandbox/权限模式可能部分屏蔽）；⑤ 无 owner 即腐烂——M4 必须真落地维护机制；⑥ 公司设备批量装 CLI 有越界观感——全用户态 brew、无 sudo、安全审计留痕。
