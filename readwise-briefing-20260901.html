3. Tailcat：没有 Tailscale 的 Tailscale ✅ Verified

不用注册账号，不用装 VPN，不用开端口，不用 root，也不改你的路由和 DNS。两台机器，发个短 token 过去，直接就连上了，全程 WireGuard 端到端加密。打得通走直连，打不通自动走 DERP。
来源：@NFTCPS · 推文 · github.com/tailscale/tailcat
Phase 1.5 验证（✅）：Tailscale 官方出品，4,857⭐ / 155 forks / BSD-3 / 推送 2026-08-31。定位 "like netcat, but over Tailscale's data plane"——剥离控制面，只留 WireGuard 加密 + NAT 穿透 + DERP 中继，token 即地址（tc:// 协议）。v0.1.0 早期阶段。
Agent 间点对点连接的极简新选项：正在推进的 Agent 加密通信项目（ntfy 中继架构）之外，Tailcat 提供了"数据面直连"的对照路线——无需账号体系适合临时性、脚本化的机器互联。早期版本，宜观察+小场景试用，不宜托底。

🧠 健脑：同质性网络与虚假共识效应 ✅ 来源可靠

网络会把边缘人聚在一起……观点明明是少数的人，长期在同质性网络中，可能会误以为他们的观点代表了大多数人的共识，这称为虚假共识效应。后果：（1）加剧对少数派观点的坚信；（2）对按多数人意愿行事的制度不满，产生被排斥感。
来源：阮一峰周刊 #410 摘录 · 原文
信息摄入端的心智防御工具：日常信息流（含本简报的信源）天然同质化，重要判断前有意识地问一句"这个'共识'是我所在的网络给我的，还是真实分布？"——决策日志里可加这个检查项。
