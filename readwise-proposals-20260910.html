CDH 高信号 Context Layer MVP

信号 @rwayne 2026-09-09 · 验证 ⚠️ Partial（方向多源支持，不赌时间线）
核心主张：不新建平台——把 Skill Hub（打包分发）、MCP Gateway Registry（治理存取）、FA2 跨台账（度量记账）三块既有拼图连成最小共享 context 层，让员工与 agent 按「最小高信号 token」原则经权限分类按需取用 context package，且每次取用可被 FA2 记账。只赌方向 + 低成本卡位。
