⭐×5✅ VerifiedLLM bug 分布迁移 + Adversarial Review

Boris Cherny（@bcherny）· Head of Claude Code @ Anthropic · 2026-08
LLMs still produce bugs, adversarial code review has been an incredibly powerful tool. LLMs still produce bugs, but those bugs are different than what they used to be. It's less off-by-ones and more about system design, ui usability, missing broader context. Some kinds of coding has been solved, but not all.

原文：x.com/bcherny/status/2087284684103537011（引用 @jarredsumner 推文）

验证报告（Phase 1.5）：
① 身份顶级一手信源：Cherny = Claude Code 创造者兼负责人、《Programming TypeScript》作者、前 Instagram server arch lead（LinkedIn / Lenny's Newsletter / Pragmatic Engineer 三源一致）。
② 关联实践链：Jarred Sumner（Bun 作者，2025-12 随 Bun 加入 Anthropic）在 Rewriting Bun in Rust（2026-07-08，53.5 万行 Zig→Rust）中系统化使用 adversarial review——独立 context window 让 Claude "exhaustively come up with reasons why the changes create bugs"。Simon Willison 专文覆盖。
③ 早期佐证：Jarred 2024 推文 "Human mistakes often look like typos, off-by-one errors… LLM mistakes often do a complete job of a wrong but related task"。
④ 内部数据互证：自家 AI Coding Eval 矩阵（n=56）显示最难 case 恰为跨文件领域模型改造、最易为局部 DTO/字段改动——与 Cherny 论断独立吻合，构成"外部专家 × 内部实验"双向验证。
为什么与你当前项目相关：judge_only 评分挤在 57–59% 无区分度，恰因 judge 未针对"system design / missing context"类缺陷设计——对抗性 judge（专门找茬的第二模型/第二 prompt）正对此症；Testing Excellence 的"边界优先"原则需升级为"context 优先"；低成本国内模型（DeepSeek/GLM）当 adversarial reviewer 是 opencode-proposal 的最佳叙事。

⭐×5✅ VerifiedThe AI Engineering Skills Map（四大技能）

Andrew Ng（@AndrewYNg）· The Batch Issue #366 · 2026-08

原文：X article · The Batch #366（匿名可读，全文已读）

#技能核心
1Building & deploying AI applicationsLLM / context engineering / RAG / agentic workflow + 统计化测量驾驭；核心能力 = disciplined evals + error analysis loops
2Software engineering fundamentalscost/scalability/reliability/security tradeoffs——防 "vibe coding" 式糟糕权衡
3Using coding agentsagent 心智模型、context 管理、verifiers/evals 闭环、何时写 spec、多 agent 编排
4Shaping the buildagent 擅长执行 spec 后，工程师价值迁移到"往 spec 里放什么"——product sense + ownership

方法论：10,000+ job postings 聚类 + 数十个专家/招聘经理结构化访谈。定位为"技能"而非"岗位"（类比 cloud）。详细版 map 将陆续发布。

验证报告（Phase 1.5）：✅ The Batch #366 原文全文读取（非仅推文摘要）；方法论与四技能均为一手提取；LinkedIn 同步发布交叉确认。数据为美国 JD 语料 → 对中国/宜家场景适用性需打折（已在 Proposal 2 诚实挑战中处理）。
为什么与你当前项目相关：① evals 是 #1 技能的核心能力——AI Coding Eval 项目的正当性获得权威外部背书；② 讲师团大纲（L0-L4 四象限）可用此框架校准缺口（如 error analysis 是否覆盖？）；③ "Shaping the build" 与你在 FY27 FA2 的"从执行者到系统设计者"叙事同构，可作启动会弹药。
